# 💜 Recovery & Renewal

> **A Privacy-First Sobriety Companion**  
> Free. Open-Source. Zero Tracking. Forever.

---

## 🌟 About

**Recovery & Renewal** is a free, privacy-first mobile app designed to support individuals in recovery from addiction. Built by someone in recovery, for those in recovery.

This repository contains the official website source code for [recoveryandrenewal.org](https://recoveryandrenewal.org), featuring:
- Privacy policy & transparency documentation
- About page & mission statement
- Community acknowledgments
- Credits & attributions

### 🎯 Our Mission

To provide a free, accessible recovery companion that respects your privacy. No data collection. No tracking. No ads. No accounts required. Just tools to support your journey, one day at a time.

---

## ✨ App Features

### 📖 Daily Readings
- **Bible Passages** - Daily scripture with multiple versions (KJV, NIV, ESV)
- **Spurgeon's Devotionals** - Morning & Evening by Charles Spurgeon
- **Simpson's Devotionals** - Days of Heaven Upon Earth by A.B. Simpson
- **Buddhist Wisdom** - Diamond Sutra, Heart Sutra
- **Taoist Teachings** - Tao Te Ching
- **Stoic Philosophy** - Marcus Aurelius & Epictetus

### 🛠️ Recovery Tools
- **Sobriety Tracker** - Count your days with milestone celebrations
- **12-Step Worksheets** - Interactive step work & journaling
- **Daily Prayers** - Recovery-focused prayers & meditations
- **Crisis Resources** - Quick access to 988 Lifeline, SAMHSA, AA/NA

### 🔒 Privacy Features
- ✅ **Zero data collection** - Nothing leaves your device
- ✅ **No analytics or tracking** - Your recovery is yours alone
- ✅ **Works offline** - No internet required after install
- ✅ **Open source** - Fully transparent codebase
- ✅ **No accounts** - Use immediately, no signup

## 🎨 Design Philosophy

Recovery & Renewal features a **cosmic-inspired aesthetic** with:
- Purple, pink, and cyan gradient themes
- Glassmorphism UI elements
- Smooth animations and breathing backgrounds
- TRIPP-inspired visual design

**Why cosmic?** Because recovery is about transformation, transcendence, and infinite possibility. 🌌

---

## 🛠️ Tech Stack

### Website
- **Frontend**: HTML5, CSS3, Tailwind CSS
- **Icons**: Lucide Icons
- **Hosting**: GitHub Pages
- **Form**: Formspree (Pioneer Team signup)

### Mobile App
- **Framework**: React Native (Expo)
- **Navigation**: React Navigation
- **Storage**: AsyncStorage (local only)
- **Build**: EAS Build
- **Version Control**: Git/GitHub
