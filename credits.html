Standing on Giants

This project wouldn't be possible without the incredible open-source tools and assets created by the community.

Core Technology

React Native & Expo

The framework that powers the mobile app, allowing us to build for both Android and iOS from a single codebase.

expo.dev

AsyncStorage

The engine behind our "Offline-First" promise. This library allows all your data to be stored securely on your own device.

Documentation

Lucide Icons

The beautiful, lightweight icons used throughout the app and this website. Open source and incredibly flexible.

lucide.dev

Tailwind CSS

The utility-first CSS framework that makes styling this website fast, responsive, and maintainable.

tailwindcss.com

Content & Assets

Morning & Evening

By Charles H. Spurgeon

These timeless devotionals are in the Public Domain. Text sourced from the Christian Classics Ethereal Library (CCEL).

King James Version (KJV) Bible

The KJV text is in the Public Domain in the United States. It serves as the foundational text for the Bible Reader module.

Stoic Texts

Selections from Marcus Aurelius (Meditations) and Seneca (Letters from a Stoic). Translations used are in the Public Domain.
